mailq

Query an IMAP mailbox from the command line.

mailq is a small personal command-line tool for searching and reading my own email. It runs entirely on my own computer and talks directly to the mail server over IMAP. There is no mailq server and no web service.

What it does

  • Searches a mailbox by sender, recipient, subject, text, date and unread status.
  • Lists folders and prints individual messages as plain text.
  • Opens folders read-only, so nothing is marked as read, moved or deleted.
mailq search --from alice --since 2026-11-01
mailq show 4821

Google sign-in

For Gmail accounts, mailq can sign in with Google (OAuth 2.0) instead of a password. It requests the https://mail.google.com/ scope, which is required for IMAP access, plus openid and email to confirm which account signed in. The resulting token is stored only in the operating system's keyring on the computer running mailq.
